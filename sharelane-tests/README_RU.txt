ShareLane: стартовый проект для автоматизированных тестов

Что внутри:
- src/test/java/ZipCodeTest.java — полученный вами файл с двумя тестами;
- pom.xml — зависимости Selenium и TestNG, нужные для запуска.

Как открыть:
1. Распакуйте архив в обычную папку.
2. Откройте IntelliJ IDEA.
3. Выберите File -> Open и укажите папку sharelane-tests (в ней должен лежать pom.xml).
4. Если IDEA спросит, доверяете ли проекту, подтвердите только если вы сами знаете источник архива.
5. Выберите JDK 17. Если его нет, установите/скачайте JDK 17 из интерфейса IDEA.
6. Дождитесь загрузки Maven-зависимостей. Нужен доступ к интернету.
7. Откройте src/test/java/ZipCodeTest.java и нажмите зелёный треугольник рядом с классом ZipCodeTest.
8. Можно также открыть вкладку Maven и выполнить Lifecycle -> test.

При первом запуске Selenium может скачать подходящий ChromeDriver. Нужны установленный Google Chrome и доступ к сайтам загрузки драйверов.

Тесты открывают https://www.sharelane.com/cgi-bin/register.py и вводят тестовые почтовые индексы 1234 и 12345.
